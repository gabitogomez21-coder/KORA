AJUSTES DE KORA

Personalidad

Estas preferencias se guardan en este dispositivo. En esta versión ajustan la configuración local; todavía no cambian un modelo de IA conectado.

Voz

Podés cargar un MP3 para guardarlo como referencia y escucharlo aquí. Esto no clona ni reproduce automáticamente esa voz en las respuestas.

Para generar respuestas con una voz personalizada hace falta un servicio de síntesis compatible, un backend seguro y autorización para usar la voz de referencia. No se enviará el archivo a ningún servicio desde esta versión.
